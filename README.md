# JSON Tools

Free online JSON tools for developers. Format, validate, convert, and compare JSON instantly.

## 🚀 Features

- **JSON Formatter** - Beautify JSON with proper indentation
- **JSON Validator** - Validate JSON and find syntax errors
- **JSON to YAML** - Convert JSON to YAML format
- **JSON to CSV** - Convert JSON arrays to CSV
- **JSON Diff** - Compare two JSON files visually
- **JSON Minifier** - Compress JSON to reduce file size

## 🔒 Privacy First

- 100% client-side processing
- No data sent to servers
- No sign-up required
- Completely free

## 🛠️ Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Monaco Editor

## 📦 Deployment

This project is automatically deployed to Hostinger via GitHub Actions.

### Setup GitHub Secrets

Add these secrets in your GitHub repository settings:

1. `FTP_SERVER` - Your FTP server address (e.g., `ftp.yourdomain.com`)
2. `FTP_USERNAME` - Your FTP username
3. `FTP_PASSWORD` - Your FTP password

### Manual Deployment

```bash
# Install dependencies
npm install

# Build for production
npm run build

# Upload the `out/` directory to your hosting
```
